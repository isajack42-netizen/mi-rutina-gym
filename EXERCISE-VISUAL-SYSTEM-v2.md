# LiftEngine Exercise Visual System — Anatomical v2

Reference target: the approved Exercise Library concept shared during acceptance.

## Visual rules

- Light neutral illustration canvas inside the dark LiftEngine UI.
- Human figure rendered as a grayscale anatomical mannequin with visible joint/torso structure.
- Primary muscles use coral `#e94f48`; secondary muscles orange `#f47a4a`; stabilizers gold `#e8c958`.
- Equipment must be recognizable and specific to the movement.
- Technique frames change the pose across the movement instead of reusing one generic silhouette.
- Mistake frames deliberately distort the relevant joint/body path and add a red error cue.
- No essential instructional text is embedded in the artwork.
- All assets keep SVG semantics and remain offline-compatible.

This system supersedes the original schematic First Pack artwork.
