# Press banca con barra — Pilot Asset Pack v1

Estado: **ready para evaluación del piloto**.

Primer conjunto de ilustraciones propias de LiftEngine Exercise Library. Usa fondo técnico neutro, equipamiento oscuro, figura anatómica simplificada, pectoral coral/rojo, tríceps y deltoides naranja, estabilizadores amarillo, azul LiftEngine para dirección correcta y rojo para errores.

Los SVG son assets del piloto funcional y conservan rutas/IDs estables para poder sustituirlos después por masters de mayor detalle sin cambiar el modelo de datos.
